# Иней 1.3.2

by Стёпчик

Мониторинг SIP-телефонов Yealink и история звонков в браузере. Статусы обновляются в открытых вкладках, а размер и порядок карточек сохраняются на сервере.

## Установка без интернета

Выберите комплект для Windows x64, Linux x64 или Linux ARM64. Скачайте архив на флешку, перенесите его на компьютер узла и распакуйте на локальный диск. Python и зависимости входят в комплект.

- Windows — `start_windows.bat`.
- Linux — `bash start_linux.sh`.

Откройте `http://localhost:8000` на компьютере узла. Пароль пользователя `admin` появится в терминале при первом запуске. [Инструкция по установке и восстановлению](offline/ИНСТРУКЦИЯ.txt).

### Ресурсы узла

Ориентиры для выделенной машины. Место на SSD указано сверх операционной системы.

| Телефонов | vCPU | ОЗУ | Свободно на SSD |
| --- | ---: | ---: | ---: |
| До 100 | 2 | 4 ГБ | 20 ГБ |
| 101–500 | 4 | 8 ГБ | 40 ГБ |
| 501–1 000 | 8 | 16 ГБ | 80 ГБ |

## Виртуальные телефоны

Запустите стенд на компьютере с комплектом. На Windows используйте `start_windows.bat --lab --open`, на Linux — `bash start_linux.sh --lab --open`. Затем откройте **Тесты → Виртуальные телефоны** или перейдите на [страницу стенда](http://127.0.0.1:18080/lab).

В стенде три виртуальных телефона, отдельные карточки и история. Можно набрать номер, ответить, удержать или перевести вызов, включить DND и посмотреть, какие события увидел мониторинг. [Руководство по стенду](simulator/README.md).
