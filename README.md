## Установка без интернета

### Windows 10 и 11 x64

1. Скачайте EXE, перенесите на компьютер узла и запустите с локального диска. При скачивании через **Code → Download ZIP** распакуйте архив и откройте тот же EXE в корне.
2. Выберите папки программы и рабочих данных. Для переноса с Rel 1.0 или 1.4.x сначала остановите прежний сервер, затем укажите папку его установки в мастере. Мастер покажет путь резервной копии.
3. Откройте панель по адресу, указанному мастером. По умолчанию это «http://localhost:8000». При чистой установке пароль пользователя `admin` появится в `users_data/first-start.txt` в выбранной папке данных. Файл удаляется после первого успешного входа.

Установщик включает Python и зависимости. При новой установке входящие подключения на выбранный порт разрешены по умолчанию для частной сети. Автозапуск включается при входе в Windows. Для восстановления, обновления и удаления снова откройте установщик.

### Linux

Проверьте архитектуру командой `uname -m`. Для `x86_64` выберите Linux x64, для `aarch64` — Linux ARM64. Комплект включает Python и зависимости для этой платформы. Linux x64 запущен в WSL Ubuntu. Для ARM64 проверены целостность и состав архива.

Распакуйте ZIP и выполните `bash start_linux.sh` в папке `MonitoringSIP`. Для установки службы и резервного копирования см. [инструкцию](offline/ИНСТРУКЦИЯ.txt).

### Диагностика

В Windows нажмите «Запустить диагностику» на итоговом экране установщика или запустите `diagnose_windows.bat` из папки программы. В Linux выполните `bash diagnose_linux.sh` из папки комплекта. Ключ `--report <путь-без-расширения>` сохранит отчёт TXT и JSON, а `--lab` проверит звонок на трёх виртуальных телефонах. При запуске напрямую укажите рабочую папку через `--data-dir`, если данные хранятся отдельно.

### Участие в карте сети

Подключённый узел проверяет по ICMP адреса, заданные администратором, и передаёт результаты в раздел «Доступность» на сервере мониторинга. Список адресов узел получает при синхронизации. Телефоны продолжают отправлять события на HTTP-адрес своего узла.

## Виртуальные телефоны

Запустите стенд на компьютере с комплектом. На Windows используйте `start_windows.bat --lab --open` из папки программы, на Linux — `bash start_linux.sh --lab --open`. Затем откройте **Тесты → Виртуальные телефоны** или перейдите на [страницу стенда](http://127.0.0.1:18080/lab).

В стенде три виртуальных телефона, отдельные карточки и история. Можно набрать номер, ответить, удержать или перевести вызов, включить DND и посмотреть, какие события увидел мониторинг. [Руководство по стенду](simulator/README.md).
