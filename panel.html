Настройка телефонов: Функции → Action URL
Для телефона с одним SIP-номером выберите его карточку: номер попадёт во все 48 URL. Для общей DECT-базы или нескольких SIP-аккаунтов выберите «Авто» — номер подставит телефон. Для Yealink скачайте CFG и импортируйте его в веб-интерфейсе телефона: Настройки → Конфигурация → Импорт CFG.
Авто: телефон должен подставлять $active_user. Если номер пустой, сервер ищет его по IP карточки или MAC, выученному после события с номером. Привязка MAC теряется при перезапуске; у общей DECT-базы номер может быть неоднозначен. Если телефон не передаёт номер, часть событий базы не удастся привязать к отдельной трубке.
CFG использует параметры Yealink T53; совместимость зависит от модели и прошивки. Импорт в ТЕЛТА «Спектр-101» пока не подтверждён. Для ручной настройки копируйте URL в одноимённые поля телефона и сохраните изменения.
