# Офлайн-мастер Инея для Windows x64

Сначала соберите `--public-node --windows-x64` через [офлайн-сборщик](../build_kit.sh). Команду запускайте на Windows из корня репозитория.

```powershell
.\offline\installer\build_windows_installer.ps1 -KitZip <публичный Windows ZIP> -Output .\dist\IneiSetup.exe -SelfTest
```

Сборщик использует установленный .NET Framework и вкладывает Windows x64-комплект в EXE. `-SelfTest` проверяет перенос, восстановление и запуск узла во временных каталогах с локальным тестовым портом. Установщик для передачи пользователю представляет собой один `IneiSetup.exe`.

По умолчанию мастер показывает условия из [`license.txt`](license.txt). Параметр `-License` позволяет указать другой файл в UTF-8. Сборщик выдаёт размер и SHA-256 готового файла.

Рабочие данные хранятся отдельно от программы. Перед переносом или восстановлением остановите прежний сервер. Мастер показывает папку резервной копии и проверяет копируемые файлы. Если новая программа не запускается, возвращаются прежние папки. После прерванного переключения выберите те же папки и повторите операцию.

Автозапуск выполняется при входе текущего пользователя в Windows. Для выбранного правила TCP-брандмауэра запрашивается повышение прав. Программа доступна в меню «Пуск» и в списке установленных приложений. При удалении рабочие данные сохраняются, пока пользователь отдельно не подтвердит их удаление.
